\## System Description

RaceDay is a full-stack web-based event management system built for the South African road running, walking, and cycling community. The platform allows Event Organizers to create and manage events, categories, and participant results, while Participants can browse upcoming events, enter events, track their personal performance history, and prepare for race day.



This repository contains Part 1 of the Portfolio of Evidence: system planning and database design, including the Entity Relationship Diagram, the API endpoint plan, and the SQL database script.



\## Roles



\*\*Organizer\*\* – Can create, edit, and delete events, manage event categories, capture participant results, and view all event enrolments.



\*\*Participant\*\* – Can create an account, browse the events, enter an event by selecting a category, view their own enrolments, and track their personal results.
